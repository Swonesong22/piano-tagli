# Piano Tagli

Calcola il piano di taglio delle tavole con il minimo spreco: schemi raggruppati,
pacchi da spuntare, stampa per l'officina.

**Apri l'app:** https://swonesong22.github.io/piano-tagli/

Funziona nel browser e, dopo la prima apertura, anche senza internet.
Sul telefono si installa come un'app:

- **Android:** apri il link con Chrome e tocca «Installa» (oppure menu ⋮ → «Installa app»).
- **iPhone:** apri il link con Safari, tocca Condividi e poi «Aggiungi alla schermata Home».

I dati inseriti restano sul dispositivo: non vengono inviati a nessun server.
